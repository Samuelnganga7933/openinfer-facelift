# OpenInfer Facelift

A cleaner interface experiment for running and inspecting inference workflows.

The project focuses on the surface around the model: choosing a workflow, sending input, seeing the result, and keeping the experience understandable.

## Stack

`JavaScript` `Vite` `Tailwind CSS` `Eleventy`

## Run it

```bash
npm install
npm run dev
```

## Preview

The repository is an interface experiment and currently does not ship with a captured public screenshot. Add one after the local app is run with its expected backend available.
